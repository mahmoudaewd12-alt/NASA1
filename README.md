# 🌕 Lunar Landing Site Navigator

### NASA Space Apps Challenge 2026

An interactive, AI-powered platform designed to explore and evaluate potential lunar landing sites near the Moon's South Pole.

## 🚀 Project Overview

The Lunar Landing Site Navigator helps users explore lunar regions, inspect scientific features, and evaluate potential landing locations using a Machine Learning model.

## ✨ Key Features

- Interactive Lunar South Pole Map.
- Lunar region exploration.
- Scientific data visualization.
- Machine Learning-based landing suitability prediction.
- FastAPI backend integration.

## 🧠 Machine Learning

The project uses a trained Machine Learning model to analyze lunar terrain features and estimate landing site suitability.

## 🛠️ Technologies

- Python
- Pandas & Scikit-learn
- FastAPI
- HTML, CSS & JavaScript
- Machine Learning

## 📂 Project Structure

- `api.py` – Backend API.
- `index-1.html` – Website interface.
- `style.css` – Website styling.
- `script.js` – Frontend functionality.
- `landing_model.joblib` – Trained ML model.
- `model_meta.json` – Model metadata.
- `nasa_moon_trek_lunar_regions_features.csv` – Lunar regions dataset.
